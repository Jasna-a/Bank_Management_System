BANK MANAGEMENT SYSTEM

Developed By : Jasna A.
Project : AI-Driven Python Programming Mini Project

Project Description

A Python-based Bank Management System developed to manage customer accounts and banking transactions in simple and efficient manner.
The system allows customers to 
-Create accounts
-Login using Secure PIN
-Check Balance
-Deposit & Withdraw Money
-View Transaction History

Technologies Used

- Python 3
- SQLite3
- VS Code

Features

- Customer account creation
- Secure PIN login
- Check account balance
- Deposit and withdraw money
- Transaction history
- Account details
- Forgot PIN

How to Run the Project

Step 1: Install Python
Download and install Python 3 from:
https://www.python.org/downloads/

Step 2: Open the Project
Open Visual Studio Code.
Select File → Open Folder.
Choose the Bank Management System project folder.

Step 3: Open Terminal
Select Terminal → New Terminal in VS Code.

Step 4: Run the Application
Enter the following command:
python app.py

Step 5: Use the Application
Create a customer account.
Log in using your PIN.
Check account balance.
Deposit or withdraw money.
View account details.
Check transaction history.

7. Database
SQLite3 is used as the database

The database stores:
Customer account information
Account balance
Secure PIN information
Banking transactions
